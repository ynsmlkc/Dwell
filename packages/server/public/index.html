How it works ↓

It only appears while you are waiting. It disappears when the answer arrives. It never interrupts a command, never opens a window, and when you are idle there is nothing there at all.

How it works

  1. 01

    Install

    One command. It edits your Claude Code settings and nothing else on the machine.

    npm i -g dwellsh && dwell init --spinner
  2. 02

    Connect your wallet

    USDC lands in the Stellar wallet you connect. You sign with Freighter; we never see a private key.

    dwell login
  3. 03

    Get paid

    While the model is working, one line sits in your status line next to what the assistant is doing. Idle means empty.

    counts only after 10 seconds on screen

What we send

Every field, in both directions. Nothing else leaves the machine.

We send

  • impression id, campaign id, duration
  • session id, client version
  • OS and architecture

We never send

  • your directory path
  • your file names
  • your prompts, your code
