One sponsored line while your agent thinks. Paid in USDC, on Stellar.

Install a small CLI. While Claude Code is working, a single line of text sits in your status line. When the answer lands, it is gone.

Shown only while you wait. Gone when the answer lands.



      
    

  


  
  

    

      
Three steps. Then you forget it is there.

      
No account, no email, no password. A command, a wallet signature, and a line that only exists while you are waiting anyway.

    


    

      

        

          01
          
Install

          
It edits your Claude Code settings and nothing else on the machine.

        

        

          
$ npm i -g dwellsh

          
$ dwell init --spinner

          
✓ statusLine installed

          
✓ spinnerVerbs installed

          
✓ hooks.UserPromptSubmit installed

          
✓ hooks.Stop installed

          
✓ daemon running

          
To undo: dwell uninstall

What leaves your machine. All of it.

      
This is the entire impression report, field for field. If it is not in this object, it is not sent.

    


    

      

        
impression reportPOST /v1/impressions


{
  id:            "01J9Z…",        // random, per impression
  campaignId:    "cmp_…",
  nonce:         "…",
  sessionId:     "…",             // random, not you
  surface:       "statusline",
  durationMs:    12400,
  clientTs:      1790000000000,
  projectKey:    "9f2c…",         // salted HMAC, never the path
  clientVersion: "0.1.16",
  os:            "darwin",
  arch:          "arm64"
}

      


      

        

          
Never sent

          
These never leave your machine in any form — not even hashed. (The projectKey above is a salted HMAC of the project, computed locally; the path itself is never sent.)
