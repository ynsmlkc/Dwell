Privacy

The CLI runs on your machine and talks to one server. This page lists everything that crosses the wire. If something is not on this list, it does not leave your computer.

Your project stays yours

The project identifier is a hash, salted with a value generated on your machine that never leaves it. Raw directory paths and file names never reach the network — not truncated, not hashed-and-sent-alongside. They are simply not part of any request.

Prompts and code are never read

The CLI does not read your prompts, your files, or the model's answers. It knows one thing: whether the assistant is currently working. That signal is what decides whether a line is shown.

IP addresses

Hashed with a server-side salt and used only for fraud checks. The raw address is never written to storage.

Your keys

The wallet private key never enters the CLI or this site. Login is a signature request handled by the Freighter extension; we receive the signed challenge and nothing else. The message you sign cannot be submitted to the network — its sequence number is zero — so it can never move anything.

The exact fields

  • impression_idrandom per shown line
  • campaign_idwhich ad was shown
  • duration_mshow long it was visible
  • session_idrotates per CLI session
  • client_versione.g. dwellsh 0.1.1
  • os / arche.g. darwin / arm64
  • project_hashsalted locally, one-way

Removal

One command. It removes only the entries we added; your own settings are untouched.

$ dwell uninstall
