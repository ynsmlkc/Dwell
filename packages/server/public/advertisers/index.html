Who sees it
Developers using Claude Code, at the moment they are idle and waiting for a model to answer. Not a feed, not a page — their own terminal.
The format
One line, plain text, 80 characters maximum including the brand and the domain. No images, no animation, no tracking pixels — there is no image channel to buy.
What counts
Only impressions displayed longer than 10 seconds. A line that flashes for two seconds is not billed.
Where the link goes
A bare domain, exactly as printed. No redirects, no query strings — the developer lands where the line says they will.

What it costs

You set the CPM. Minimum $0.10 per 1000 impressions; publishers receive 50%. There is no pricing table — the number is yours to choose.
